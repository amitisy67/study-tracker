# 📚 Study Tracker

## About the Project

Study Tracker is a simple Python-based command-line application designed to help users manage and track their study sessions. It combines a study session tracker with a Pomodoro timer and stores session data using JSON.

## What Does It Do?

The application allows users to record their study sessions, view and remove saved sessions, and start a Pomodoro timer for focused study. All study session data is stored in a JSON file, so the information remains available after closing and reopening the program.

## Technologies Used

* **Python**
* **JSON**
* **Object-Oriented Programming**
* **File Handling**

## Features

* ➕ Add a study session with a subject and duration
* 👀 View saved study sessions
* 🗑️ Remove study sessions
* 🍅 Start a 25-minute Pomodoro timer
* 💾 Save study data to a JSON file
* 📂 Load saved data when the application starts
* 🖥️ Simple command-line interface

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/study-tracker.git
```

### 2. Open the project folder

```bash
cd study-tracker
```

### 3. Run the program

```bash
python main.py
```

Make sure `main.py`, `pomodoro.py`, and `data.json` are in the same project folder.
